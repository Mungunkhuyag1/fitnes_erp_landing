# Заалны гэрэл зураг

Энд дараах нэрээр **хэвтээ (landscape)** зураг тавина. Нэр нь кодод
шигдсэн тул ЯГ ИЙМ байх ёстой.

| Файл | Юу | Санал болгох өргөн |
|---|---|---|
| `hall-01.jpg` | Заалны ерөнхий харагдац — нүүрний гол зураг | 2000px |
| `gear-01.jpg` | Хүчний бүс, тоног төхөөрөмж | 1400px |
| `cardio.jpg`  | Кардио бүс | 1400px |
| `sauna.jpg`   | Сауна | 1400px |
| `shower.jpg`  | Шүршүүр | 1400px |
| `locker.jpg`  | Шүүгээний өрөө | 1400px |

⚠ Босоо зураг бүтэн дэлгэцийн нүүрэнд тохирохгүй.
⚠ Хүн танигдахаар бол зөвшөөрөл хэрэгтэй.
⚠ 500KB-аас хэтэрвэл хуудас удаашрана — Next.js өөрөө хувиргах ч
   эх файл том байх тусам build удаан болно.

Зураг дутуу байвал хуудас эвдрэхгүй: `src/app/page.tsx` дотор
байхгүй зургийг алгасах тул эхлээд байгаагаа тавьж болно.
